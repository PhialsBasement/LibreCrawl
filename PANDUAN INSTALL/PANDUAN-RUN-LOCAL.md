## Apa itu LibreCrawl?

Program untuk ngecek isi website — halaman apa aja yang ada, link rusak, judul halaman, dll. Dipakai lewat browser di komputer sendiri (local).

## Butuh waktu berapa lama?

- **Pertama kali:** sekitar 10-30 menit (karena download bahan).
- **Pakai lagi di kemudian hari:** cukup 2-3 menit.

## Yang kamu butuhin:

1. Komputer (Windows 10/11 atau macOS).
2. Koneksi internet (untuk download bahan di awal).
3. Browser modern (Chrome / Firefox / Safari / Edge).
